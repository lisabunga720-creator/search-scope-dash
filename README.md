# Backlink Insights Dashboard

"Build a modern, clean, dark-mode SEO Backlink Research Dashboard for an agency.

Core Features:

A clean input field where I can enter a single domain name (e.g., example.com).

A primary button labeled 'Check Metrics'.

A loading skeleton/spinner state while waiting for the response.

A result card or section that displays:

The Domain Name

Domain Authority (DA) score in a large, prominent badge

A status indicator (e.g., Green if DA is above 30, Yellow if 15-30, Red if below 15)

A history table below that records previous domains checked during the current session so I can compare multiple sites easily.

An export button to download the checked history as a CSV file for client reporting.

Please design it to look professional, polished, and intuitive."
